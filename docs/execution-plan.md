# 实现与限制

## 保存格式

插件验证网关的 v2 记录版本、分组及原请求模型的筛选摘要。命中后写入 `rawdata-v2/YYYY/MM/DD/gateway/<UUID>.json`，随后追加 `rawdata-v2/jsonl/YYYY-MM-DD/模型/模型-日期-时间戳-序号.jsonl`。两个写入器都只接收脱敏数据。
分片在达到上限、下一条放不下或跨 UTC 日期时封口，单片上限 10,000,000,000 字节。启用 S3 时上传到 `s3://bucket/rawdata-v2/YYYY-MM-DD/模型/文件名`。上传成功后删除本地分片，失败时保留并重试。
单条 JSON 使用临时文件原子改名，总额度 100,000 条、10 GiB。配额耗尽时该次归档失败。单条 JSON 已保存但聚合失败时保留单条文件，向网关报告聚合错误。

## 宿主行为

每次业务调用尝试单独生成记录。`request` 是上游请求正文，HTTP/SSE `response` 是上游原始文本，WebSocket `response` 是有序消息字符串数组。`response_complete` 标记完整性，`transport` 区分传输，收到 HTTP 状态时带 `http_status`。

网关在进入异步队列前清洗档案副本。归档仍包含客户的业务内容，应限制服务器目录、下载权限和 S3 访问。队列和内存预算不足时丢弃采集，转发继续。

## 插件页

空配置使用 `$SUB2API_PLUGIN_STATE_DIR/archive`，宿主必须提供绝对的持久化状态目录。自定义服务器绝对目录仅放在高级设置；不默认写进工作目录。管理员选择日期后查看当天文件，并可逐条下载 JSON。下载由宿主管理 API 鉴权，插件 iframe 通过 UI Bridge 请求，不能直接读取服务器路径或管理凭据。
分组与模型使用 `group_ids` 和 `models`，任一名单为空或网关协议信息缺失时拒收。升级后仅查看与上传 `rawdata-v2/` 下的新数据。旧目录、分片、云端对象及备份由运维单独管理。

## 未覆盖

- 图片/视频二进制素材、异步任务的最终结果关联。
- 筛选导出、自动清理、跨实例汇总、统计面板和漏存告警。
- 大于 60 MiB 的单条调用；gRPC 请求/响应上限为 64 MiB。
- 部署需要配套升级网关和插件，现有签名包需从新源码重新构建。

队列溢出、插件停用、宿主退出或超限均可能造成记录缺口；模型调用不等待采集确认。真实模型调用及其费用不属于本地测试，部署验收需另行执行。
