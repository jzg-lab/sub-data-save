# 实现与限制

## 保存格式

插件收到一条完整 JSON 后原样落盘，外层记录结构包含版本、完成时间、供应商、上游账号 ID、模型，以及字符串形式的 Request/Response 正文。字符串包装让 JSON 和 SSE 正文读回时不丢空白、转义和事件顺序。

路径为 `目录/YYYY/MM/DD/gateway/记录ID.json`。文件经临时文件写入后原子改名；启动时重建额度用量并清理未提交的临时文件。首版额度固定为 100,000 条、10 GiB 总量、60 MiB 单条。

## 宿主行为

Claude 与 OpenAI 的 HTTP 业务路径在请求处理确认成功且客户端未断开后才尝试保存。非流式要求有效 JSON 且读到 EOF；SSE 要求收到完整成功终止事件且无错误/不完整帧或读取异常，不要求终止事件之后继续等连接关闭。记录进入最多 128 条、合计 128 MiB 的有界队列，同时最多观察 128 个调用，正文与编码工作区受宿主共享内存预算约束；没有共享预算时采用 128 MiB 回退预算。预算不足时即使单条小于 60 MiB 也会放弃。采集插件单独运行，不占用 Cookie Pin 的出站插件槽位。采集失败只会漏存，不改变模型响应。

已接入 Claude Messages、Responses、Chat Completions 以及 OpenAI Responses、Chat Completions、Messages 转换入口，包含普通 HTTP 直通路径；OpenAI 的 Cookie Pin HTTP 返回也经过相同正文观察。认证头、Cookie、代理凭据不会写入档案。原始响应正文作为字符串保存，不转换为面向客户端的响应对象。

## 插件页

空配置使用 `$SUB2API_PLUGIN_STATE_DIR/archive`，宿主必须提供绝对的持久化状态目录。自定义服务器绝对目录仅放在高级设置；不默认写进工作目录。管理员选择日期后查看当天文件，并可逐条下载 JSON。下载由宿主管理 API 鉴权，插件 iframe 通过 UI Bridge 请求，不能直接读取服务器路径或管理凭据。

## 首版未覆盖

- WebSocket、图片/视频二进制素材、异步任务的最终结果关联。
- ZIP、筛选导出、自动清理、跨实例汇总、统计面板和漏存告警。
- 大于 60 MiB 的单条调用；gRPC 请求/响应上限为 64 MiB。
- 实际部署、压力测试、跨容器持久化验证、真实 Cookie Pin 联调及正式发布。签名候选包已在本地构建。

队列溢出、插件停用、宿主退出或超限均可能造成记录缺口；模型调用不等待采集确认。真实模型调用及其费用不属于本地测试，部署验收需另行执行。
