# 已确认需求

用户于 2026-11-08 至 2026-11-09 确认以下需求，目标是为知识库和后训练积累可追溯的原始数据。
用户已创建独立仓库并授权上传当前需求与执行计划；当前为文档阶段，采集接口、插件功能和部署尚未实施。

- 覆盖所有厂商和账号类型，采集实际发往上游的完整请求及上游原始响应；
  原有字段（包括已有的 `rawdata`）、系统提示词、工具定义、工具调用和用量等内容完整保留。
  正文不做业务格式转换；外层档案与原始正文分开，流式事件保留原文和顺序。
- 每次成功且完整的上游调用保存一个 JSON；失败尝试、流内报错、残缺响应排除。
  真实业务才进入数据集，探针、账号测试和健康检查排除；成功筛选不等于答案质量审核。
- 允许在正文之外附加时间、厂商、实际模型、调用和会话关联等少量来源信息；
  缺失关联信息标明缺失，不虚构，不为补日志再次调用模型。
- **业务优先**：磁盘满、写入失败、队列拥塞或采集插件故障不使模型调用失败；
  采集队列必须有容量上限，资源不足时放弃整条采集。漏存数量与原因单独统计并告警，
  不将报错内容混入数据集，接受异常期间的数据缺口。
- 插件单独仓库维护；网关仓库负责采集接口，插件仓库负责保存和发布，
  与现有 Cookie Pin 传输插件共存。原始档案与后续知识提取、去重和训练格式加工分开。
- 第一版保存在网关服务器本地持久化目录，管理员可从后台插件页面下载采集的数据到自己的电脑。
  下载对象是采集档案；本次确认不涉及插件安装包下载。具体单条及批量下载方案见执行计划。

执行顺序、验收及待核实技术细节见[执行计划](execution-plan.md)。
