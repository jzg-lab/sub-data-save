# 第一版范围

- 只处理 Anthropic/Claude 与 OpenAI 的普通 HTTP 模型调用，包含完整结束的 HTTP 流式响应；WebSocket、图片/视频素材和异步任务暂不处理。
- 每次成功且完整的上游调用保存一个 JSON，包含实际发出的请求正文、上游原始响应正文及少量来源信息；不保存认证头、Cookie 或代理凭据。
- 失败响应、流内报错、断流、客户端断开、超限或缺少完整结束的记录不保存。探针、账号测试和健康检查不进入采集路径。
- 默认无需配置目录，档案保存在宿主提供的持久化状态目录下；高级设置允许指定绝对目录。按 UTC 日期分目录，每次调用一个 JSON。插件页按日期列出记录并逐条下载，不做 ZIP。
- 采集使用有界异步队列；队满、磁盘错误或插件不可用时放弃记录，不影响模型请求。首版固定总记录数、总空间、单条大小和队列额度。
- 采集内容可能包含敏感对话，应限制服务器目录权限；档案和下载包不提交 Git。

正式包预先签名；宿主内置本插件限定 ID 的发布者公钥，无需人工改信任配置。宿主需一次升级补齐通用采集协议，采集不占用 Cookie Pin 槽位。

完整的边界和已知限制见[实现与限制](execution-plan.md)。
