# 第一版范围

- 只处理 Anthropic/Claude 与 OpenAI 的普通 HTTP 模型调用，包含完整结束的 HTTP 流式响应；WebSocket、图片/视频素材和异步任务暂不处理。
- 每次成功且完整的上游调用保存一个 JSON，包含实际发出的请求正文、上游原始响应正文及少量来源信息；不保存认证头、Cookie 或代理凭据。
- 失败响应、流内报错、断流、客户端断开或缺少完整结束的记录不保存。单条超过 60 MiB 时两种格式都拒绝；逐条档案达到总条数或总容量后只停止原始 JSON，JSONL 仍继续写入。探针、账号测试和健康检查不进入采集路径。
- 原始 JSON 按 UTC 日期保存并保留逐条下载；另按 `requested_model`（缺失时回退 `model`）聚合 JSONL。JSONL 每个文件最多 10,000,000,000 字节，滚动文件名包含模型、UTC 日期、时间戳和序号。
- 配置 S3 bucket 与 AWS region 后，封口 JSONL 上传到 `bucket/YYYY-MM-DD/model/model-date-timestamp-sequence.jsonl`；使用 AWS 默认凭证链，不在插件配置中保存密钥。未配置 bucket 时仅本地保存。
- 采集使用有界异步队列；队满、磁盘错误或插件不可用时放弃记录，不影响模型请求。逐条下载档案达到总条数或总容量上限后，新的记录仍继续进入 JSONL；单条大小和队列额度保持固定。
- 采集内容可能包含敏感对话，应限制服务器目录权限；档案和下载包不提交 Git。

- 用户可选择多个采集分组与模型；新记录只有 `group_id` 和原始 `requested_model` 同时命中配置名单才保存。任一名单为空或元信息缺失时 fail-closed。
正式包预先签名；宿主内置本插件限定 ID 的发布者公钥，无需人工改信任配置。宿主需一次升级补齐通用采集协议，采集不占用 Cookie Pin 槽位。

完整的边界和已知限制见[实现与限制](execution-plan.md)。
