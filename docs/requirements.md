# Rawdata v2 范围

- 采集 Anthropic/Claude 与 OpenAI 业务 HTTP、SSE 及 OpenAI WebSocket 的上游请求与返回。探针、素材下载和异步任务关联不在此范围。
- 每次实际尝试独立保存，错误响应保留收到的内容，断流标明完整性。每条先写 JSON，随后用同一条脱敏记录聚合 JSONL。
- 网关在内存中处理已知 API key 和可识别的凭据字段。关键词 `ciyuan.fast`、`ciyuan`（忽略大小写）、`词元` 替换为 `中转`。保留正文中其他原有字段。
- 本地使用 `rawdata-v2` 子目录，S3 使用同名前缀。归档按 UTC 日期和处理后的请求模型分片，每片最多 10,000,000,000 字节。
- 单条超过 60 MiB、单条档案总配额耗尽、空间不足、无法安全清洗或队列已满时可漏存。采集失败不阻断模型调用。
- 采集内容可能包含敏感对话，应限制服务器目录权限；档案和下载包不提交 Git。

- 用户可选择多个采集分组与模型；新记录只有 `group_id` 和原始 `requested_model` 同时命中配置名单才保存。任一名单为空或元信息缺失时 fail-closed。
正式包预先签名；宿主内置本插件限定 ID 的发布者公钥，无需人工改信任配置。宿主需一次升级补齐通用采集协议，采集不占用 Cookie Pin 槽位。

完整的边界和已知限制见[实现与限制](execution-plan.md)。
